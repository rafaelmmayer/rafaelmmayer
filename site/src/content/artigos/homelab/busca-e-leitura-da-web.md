## Ideia do artigo

Este texto pode falar de uma parte menos óbvia do homelab: não só hospedar páginas e painéis, mas criar uma camada própria para buscar e ler conteúdo da web.

SearXNG e Firecrawl cumprem papéis diferentes. Um ajuda a encontrar. O outro ajuda a transformar uma página em conteúdo que dá para resumir, comparar, guardar ou usar como contexto para um agente.

## Pontos para desenvolver

- Busca local como alternativa, não como religião.
- Firecrawl como leitor de páginas em markdown limpo.
- Onde isso ajuda em documentação, pesquisa e comparação de ferramentas.
- Limites: login, paywall, bloqueios, páginas dinâmicas.
- Como isso muda o jeito de pedir pesquisa para o Bob.

## Possível estrutura

1. O problema de pesquisar e perder contexto.
2. SearXNG para descoberta.
3. Firecrawl para leitura.
4. O fluxo com agente: buscar, extrair, resumir, decidir.
5. O que ainda precisa melhorar.

## Notas soltas

Pode valer um exemplo real com documentação técnica, desde que seja simples e não vire propaganda de ferramenta.
